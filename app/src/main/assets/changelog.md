## Готовится
- Готовые версии приложения теперь выкладываются на GitHub: github.com/EugeneRymarev/t2lite/releases. Там же список изменений каждой версии

## 1.1.12 · build 18 · 25.11.2026
- Безопасность: приложение больше не записывает в служебный журнал телефона коды из SMS, ключи входа, баланс и переписку с поддержкой. Раньше их можно было прочитать, подключив телефон проводом к компьютеру
- Безопасность: ключи входа в аккаунт теперь лежат на телефоне в зашифрованном виде — замок от них хранит защищённое хранилище Android. Заново входить по SMS после обновления не нужно
- Безопасность: данные приложения больше не попадают в резервные копии Google и не переносятся на другой телефон. На новом телефоне нужно один раз войти по SMS
- Безопасность: ключ входа отправляется только на серверы t2. Если ссылка (например, на запись звонка) вдруг ведёт на чужой сайт, ключ туда не уйдёт
- Безопасность: приложение работает только по защищённому соединению (https) — и запросы, и страницы сайта внутри приложения
- «Вопросы и ответы»: внутри приложения открываются только страницы сайта t2. Статью с другого сайта можно открыть кнопкой «Открыть в браузере»
- «Салоны связи»: где вы находитесь, узнаёт только сам сайт t2, а не чужие страницы, встроенные в него
- Ссылки из чата поддержки и со страниц t2 передаются другим приложениям, только если это обычные ссылки (сайт, телефон, карта). Подозрительные ссылки приложение пропускает
- Записи звонков помощника сохраняются только в свою папку, даже если сервер пришлёт неправильное имя файла
- При выходе из аккаунта с телефона стираются скачанные записи звонков помощника, запомненная почта для выписки и сохранённые «Вопросы и ответы»
- Исправлена редкая ошибка, из-за которой приложение могло неожиданно закрыться, когда обновляло сразу несколько данных
- Сборка на компьютере: пароль от ключа подписи больше не виден другим программам, пока создаётся ключ. Дополнен список файлов, которые нельзя выкладывать в интернет: ключи подписи, готовые APK, записи трафика
- Из текста программы убран настоящий номер телефона, оставшийся в примерах

## 1.1.11 · build 17 · 24.11.2026
- Новый раздел «Мои заявки» (вкладка «Связь»): заявки, которые оформили в поддержке или в салоне, их номер, статус («Рассматриваем», «Готовим решение», «Решена») и ответ специалиста
- Новый раздел «Салоны связи t2» (вкладка «Связь»): адреса салонов t2 и часы работы на карте и списком, как в оригинальном приложении. Телефоны и маршруты открываются в своих приложениях
- «Финансы»: история только за последние 6 месяцев (дальше t2 её не отдаёт) — больше нет ошибки в конце ленты и на старых месяцах
- Новый раздел «Вопросы и ответы» (вкладка «Связь»): темы и статьи помощи t2 и поиск ответа по словам. Статья открывается прямо в приложении, список тем виден даже без интернета
