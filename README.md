# t2 Lite

Лёгкое неофициальное приложение для абонентов t2 на Android. В нём только самое нужное из «Мой t2»: баланс, остатки, маркет, финансы, звонки помощнику и чат поддержки. Без рекламы, баннеров и лишних экранов.

> [!IMPORTANT]
> **Это неофициальное приложение.** Его сделал обычный пользователь для себя, а не компания t2 (ООО «Т2 Мобайл»). Название t2 используется только чтобы было понятно, для какого оператора приложение. Приложение общается с теми же серверами, что и официальное «Мой t2», поэтому может перестать работать, если t2 их изменит. Пользуйтесь на свой страх и риск; за списания, блокировки и ошибки автор не отвечает. По вопросам связи и тарифов обращайтесь в официальную поддержку t2.

## Что умеет

**Главная**
- Вход по коду из SMS. Вход запоминается, код заново вводить не нужно
- Баланс, дата следующего списания и сколько нужно доплатить
- Остатки по тарифу: интернет, минуты, SMS
- Финансы: за что и сколько списано за месяц, все пополнения, выписка (детализация) на почту

**Маркет**
- Продажа и покупка минут, гигабайт и SMS

**Связь**
- Звонки голосового помощника: список, запись разговора с плеером и расшифровка. Вместо номера видно имя из контактов
- Чат поддержки
- Мои заявки: что оформили в поддержке или в салоне и что ответил специалист
- Салоны связи на карте и списком
- Вопросы и ответы с поиском

**Настройки и другое**
- Виджет на главный экран: баланс, доплата и остатки. Светлый, тёмный или как на телефоне
- Напоминание о пополнении за 3 дня до списания, если денег не хватает
- История версий: что нового в каждой версии

## Как установить

1. Откройте страницу [Releases](https://github.com/EugeneRymarev/t2lite/releases/latest) и скачайте файл `t2lite-….apk`.
2. Откройте его на телефоне. Если телефон спросит, разрешите установку из этого источника.
3. Войдите по номеру и коду из SMS.

Новые версии ставятся поверх старой, данные и вход сохраняются. Готовая сборка сделана для телефонов с 64-битным процессором (arm64), это почти все телефоны последних лет. Нужен Android 8.0 или новее.

## Ваши данные

- Номер и ключи входа хранятся только на телефоне, в зашифрованном виде.
- Ключ входа отправляется только на серверы t2 (`*.t2.ru`). Чат поддержки работает через сервис Webim, а карта салонов открывает страницу сайта t2, так же как в официальном приложении.
- Никакой аналитики, рекламы и сбора статистики.
- Данные не попадают в резервные копии Google. При выходе из аккаунта они стираются с телефона.

## Как собрать самому

Нужна [Android Studio](https://developer.android.com/studio) (или JDK 17+ и Android SDK 35). Скрипт `build.bat` работает на Windows.

**Проще всего:** откройте папку проекта в Android Studio и нажмите ▶ Run.

**Готовый APK на Windows:** дважды щёлкните `build.bat`. Он покажет меню, сам увеличит номер версии, соберёт APK в папку `dist` и при желании поставит его на телефон по проводу. При первой сборке он создаст ключ подписи `keystore\t2lite-release.jks` и файл с паролями `keystore.properties`.

> [!WARNING]
> Сохраните копию `keystore\t2lite-release.jks` и `keystore.properties` в надёжном месте (не на GitHub!). Без них нельзя будет выпустить обновление, которое встанет поверх уже установленного приложения.

**Из командной строки (Linux, macOS, Windows):**

```bash
./gradlew assembleDebug     # отладочная версия, ключ не нужен
./gradlew assembleRelease   # версия для выпуска (без keystore.properties подписывается отладочным ключом)
```

## Выпуск новой версии

Релиз на GitHub собирается сам: достаточно отправить метку (тег) с номером версии. Робот GitHub соберёт APK, подпишет его вашим ключом и выложит на страницу Releases вместе со списком изменений.

### Один раз: добавить ключ подписи в GitHub

GitHub должен подписывать APK тем же ключом, что и ваш компьютер, иначе обновление не встанет поверх. Ключ и пароли хранятся в «секретах» репозитория: их никто не видит, даже вы после сохранения.

Дважды щёлкните `github-secrets.bat`. Он сам возьмёт ключ и пароли из `keystore.properties` и:
- если установлена программа [GitHub CLI](https://cli.github.com/) и вы в ней вошли (`gh auth login`), добавит всё сам;
- если нет, по очереди скопирует каждое значение и откроет нужную страницу GitHub. Там впишите имя, нажмите Ctrl+V и **Add secret**.

Нужны 4 секрета (Settings → Secrets and variables → Actions):

| Имя | Что это |
|---|---|
| `KEYSTORE_BASE64` | файл ключа `keystore\t2lite-release.jks`, переведённый в текст |
| `KEYSTORE_PASSWORD` | пароль от файла ключа (`storePassword` в `keystore.properties`) |
| `KEY_ALIAS` | имя ключа (`keyAlias`) |
| `KEY_PASSWORD` | пароль от ключа (`keyPassword`) |

### Каждый раз: выпустить версию

1. Пока работаете, записывайте изменения строками `- …` под заголовком `## Готовится` в [`app/src/main/assets/changelog.md`](app/src/main/assets/changelog.md).
2. Соберите и проверьте APK через `build.bat`. Он увеличит версию в `version.properties` и заменит «Готовится» на номер версии и дату.
3. Отправьте изменения и метку версии на GitHub (PowerShell, в папке проекта):

```powershell
# Взять номер версии из version.properties (например, 1.1.13)
$v = (Select-String -Path version.properties -Pattern '^VERSION_NAME=(.+)').Matches[0].Groups[1].Value.Trim()
# Запомнить все изменения
git add -A
git commit -m "Версия $v"
# Поставить метку версии: именно она запускает выпуск релиза
git tag "v$v"
# Отправить на GitHub и изменения, и метку
git push origin HEAD "v$v"
```

То же одной строкой:

```powershell
$v = (Select-String -Path version.properties -Pattern '^VERSION_NAME=(.+)').Matches[0].Groups[1].Value.Trim(); git add -A; git commit -m "Версия $v"; git tag "v$v"; git push origin HEAD "v$v"
```

Через несколько минут релиз появится на странице Releases. Ход сборки видно на вкладке **Actions**. Метка должна совпадать с версией в `version.properties`, иначе робот остановится и напишет почему.

Кроме релизов, при каждой отправке кода робот делает проверочную сборку. Её APK можно скачать на вкладке Actions → нужный запуск → Artifacts.

## Как устроено

- Kotlin, Jetpack Compose (Material 3), Retrofit + OkHttp, DataStore, Glance (виджет), WorkManager, Webim SDK (чат)
- Android 8.0+ (minSdk 26), targetSdk 35
- `app/src/main/java/ru/myt2lite/`:
  - `data/` вход, ключи, баланс, остатки, маркет
  - `ui/` экраны и вкладки
  - `finance/`, `issues/`, `offices/`, `help/`, `voice/`, `chat/` разделы приложения
  - `widget/` виджет, `reminder/` напоминания, `changelog/` история версий
- `build.ps1` / `build.bat` сборка на Windows, `github-secrets.ps1` / `.bat` секреты для GitHub
- `.github/workflows/` проверочная сборка (`build.yml`) и выпуск релиза по метке (`release.yml`)
- `PROGRESS.md` подробный дневник разработки

## Отказ от ответственности

Проект не связан с ООО «Т2 Мобайл» и не одобрен им. Товарные знаки t2 и «Мой t2» принадлежат их владельцам. Приложение распространяется «как есть», без каких-либо гарантий.
